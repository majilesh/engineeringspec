Replay the experiment

From the EngineeringSpec checkout, build the CLI and run the standalone example.

npm ci
npm run build
node examples/checkout-simulation/demo.mjs

The command creates a temporary Git repository and prints the location of its traces, evidence envelopes and offline HTML briefs. Save the brief locally and open it in a browser.

The simulator controls a single order, its bank, receipt store, virtual clock and retry schedule. The 128 seeds repeat a small set of fault windows and response timings. The same external decisions drive both revisions. The fix reconciles an existing bank charge and writes the receipt idempotently.
