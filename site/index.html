One engineering contract. Any coding agent.

The open change-control layer gives coding agents, reviewers, and CI one reviewed, base-pinned answer to what may change and which engineering obligations apply.

Get startedExplore contractsView examples

Agent-neutral

The same on-disk contract can guide Codex, Claude Code, Cursor, CI, and human review.

Fail closed

Uncovered, ambiguous, or denied paths cannot borrow authority from a workspace proposal.

Standards-friendly

Reference OpenAPI, JSON Schema, SARIF, JUnit, OPA, and other authoritative formats.

npx --yes @engineeringspec/cli@0.1.0-rc.16 adopt . --quickstart --maintainer @your-org/platform --dry-run
npx --yes @engineeringspec/cli@0.1.0-rc.16 propose --id ES-change --title "Change" --path 'src/example/**' --output docs/engineering-specs/ES-change.engineering-spec.md --dry-run
engineeringspec next
engineeringspec work ES-change
engineeringspec finish ES-change --format markdown
