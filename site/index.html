Change authority for AI coding agents.

Authority comes from an approved contract on the trusted Git base—not from a workspace draft. Start in advisory mode, then add required checks and maintainer ownership for production enforcement.

Repository source is prepared as the unpublished RC17 compact PermissionTicket candidate. The runnable package command remains pinned to published RC16 until separate publication approval.

npx --yes @engineeringspec/cli@0.1.0-rc.16 adopt . --quickstart --maintainer @YOUR_GITHUB_USER_OR_TEAM --dry-run

engineeringspec next
engineeringspec work ES-change
engineeringspec finish ES-change --format markdown
